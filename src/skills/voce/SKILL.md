# VOCE Explore

Shows VOCE, an external connected app, as an opportunity. Not a normal write skill. Describes the skill only; nothing here executes.

## When to use
- Nothing more urgent applies (lowest priority; surfaces in the "all set" state).

## When not to use
- Never competes with actionable skills.

## States
- No VOCE profile: "Create your VOCE profile and build your AI visibility." Actions: Preview VOCE, Create VOCE Profile.
- Has VOCE profile: "Your VOCE profile is ready." Shows AI Authority Score, Articles, Questions answered. Actions: Preview VOCE, Open VOCE.

## Required data
- `graph.voce`

## Read actions
- None (stats come from the graph)

## Write actions
- None. Buttons go to a mock external URL.

## Approval requirement
- None.

## Allowed model
- `none`
